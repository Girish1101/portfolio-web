1. Executive Summary & Challenge Objectives

The Skillinf Portfolio Design Hackathon 2026 tests participants on their ability to build a world-class digital portfolio that balances technical excellence, original creative flair, micro-interactions, responsive ergonomics, and high-conversion personal branding.

The Winning Formula: Judges review hundreds of portfolios. Standard cookie-cutter templates will be filtered out immediately. To secure a top rank, your portfolio must provide an unforgettable "First 10-Second Wow Factor" (fluid visual identity & 3D canvas), followed by rock-solid engineering substance (interactive project case studies, high performance Lighthouse score, and working functional utilities).
1. Deliverable 1: Live URL
High-speed, production-grade deployment on Vercel with zero latency, custom domain or clean URL, SSL enabled, and fully accessible without login gates.
2. Deliverable 2: Resume PDF
Modern, ATS-friendly, single/two-page PDF resume uploaded to Unstop and also viewable/downloadable directly from the live portfolio website.

5. Implementation Sprints & Milestone Schedule

A rigorous, structured 5-stage sprint to transition from empty folder to award-ready deployment:

Sprint 1: Architecture & Scaffolding
  • Initialize Next.js 15 project with TypeScript and Tailwind CSS
  • Configure font families (Plus Jakarta Sans & JetBrains Mono)
  • Setup color variables, dark/light theme provider, and global CSS
  • Install Lucide icons, Framer Motion, and utility libraries
Sprint 2: Hero & Bento Showcase
  • Build responsive Navigation bar with mobile hamburger menu
  • Implement Hero section with dynamic headline and magnetic CTAs
  • Integrate 3D Canvas / interactive particle background
  • Develop high-aesthetic Bento Grid with live stat cards
Sprint 3: Projects & Skills Engineering
  • Format 3-4 flagship projects with architecture descriptions
  • Add live preview links, GitHub repository buttons, and tech tags
  • Construct interactive categorized Skills Matrix with search filter
  • Build Experience, Education, and Hackathon Milestone Timeline
Sprint 4: Interaction Polish & Easter Eggs
  • Implement Command Palette (Ctrl+K) for keyboard navigation
  • Build Contact section with working message handler & copy toast
  • Embed interactive PDF Resume viewer and direct download button
  • Add smooth scroll, micro-animations, and confetti triggers
Sprint 5: Production Deployment & Unstop Submission
  • Audit Lighthouse metrics: aim for 95+ in Performance, Accessibility, SEO, and Best Practices
  • Deploy project directly to Vercel production edge with custom or clean domain
  • Conduct cross-browser and cross-device testing (iPhone Safari, Android Chrome, Mac Safari, Windows Chrome)
  • Verify PDF resume is valid, formatted cleanly, and ready for upload alongside the live portfolio link on Unstop

6. 20-Point Pre-Submission Audit Checklist

Accessibility & UX Standards
  • Zero broken links (all external links open in target="_blank" with rel="noopener")
  • Mobile viewport responsive down to 320px width without horizontal scroll
  • Touch targets are at least 44x44px for thumb tap ergonomics
  • Color contrast ratio meets WCAG AA standards (4.5:1 minimum)
  • ARIA labels attached to all icon-only buttons and theme toggles
Hackathon Compliance & Delivery
  • Live URL is publicly accessible without login/password gates
  • Resume PDF is current, matches portfolio content, and is under 5MB
  • No sensitive private information (passwords, private API keys, full address)
  • Live demo links and GitHub repositories for all listed projects work
  • Favicon, page title, and OpenGraph social banner preview configured
